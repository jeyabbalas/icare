## Model validation

Calibration and discrimination in a cohort or a nested case-control
study.

- [`ModelValidation()`](https://jeyabbalas.github.io/icare/reference/ModelValidation.md)
  : Validate an absolute risk model in a cohort or a sample from a
  cohort
- [`plotModelValidation()`](https://jeyabbalas.github.io/icare/reference/plotModelValidation.md)
  : Plot the results of a model validation
- [`print(`*`<icareValid>`*`)`](https://jeyabbalas.github.io/icare/reference/icareValid-methods.md)

  : Print and plot model validation results
